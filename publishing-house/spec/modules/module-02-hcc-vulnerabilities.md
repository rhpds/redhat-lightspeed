# Module Outline: module-02-hcc-vulnerabilities

### Brief Overview

This module guides learners through the vulnerability management workflow in Red Hat Lightspeed at the Hybrid Cloud Console. Using a RHEL 9.7 host that is already registered and reporting to the Hybrid Cloud Console, learners identify CVEs, examine a specific vulnerability (CVE-2025-43458 / WebKitGTK), generate an Ansible remediation playbook, filter by severity, and produce executive and custom PDF vulnerability reports. The module is entirely GUI-based with no terminal commands required.

### Audience and Time

- **Target persona:** Linux system administrators and IT security operators; beginner level
- **Prerequisites for this module:** Completion of module 01 (Overview); access credentials for the shared Hybrid Cloud Console organization rhpd-lightspeed-lb1187
- **Estimated duration:** 35 minutes

### Learning Objectives

- Analyze CVE exposure on internet-connected Red Hat Enterprise Linux hosts using the Red Hat Lightspeed vulnerability service at the Hybrid Cloud Console
- Secure Red Hat Enterprise Linux systems by generating Ansible remediation playbooks for identified CVEs through Red Hat Lightspeed
- Explore vulnerability reporting capabilities including executive summary and CVE-filtered PDF reports

### Lab Structure

| Section | Title | Duration |
|---------|-------|----------|
| 1 | Log in to the Hybrid Cloud Console | 3 min |
| 2 | View and explore the vulnerability dashboard | 5 min |
| 3 | List all systems with a specific CVE (CVE-2025-43458) | 7 min |
| 4 | Generate an Ansible remediation playbook | 7 min |
| 5 | Filter by critical and important CVEs | 5 min |
| 6 | Generate executive and custom PDF reports | 8 min |

### Detailed Steps

1. Open a browser and navigate to console.redhat.com.
2. Log in using the shared lab credentials for the rhpd-lightspeed-lb1187 organization.
3. Navigate to the Red Hat Lightspeed Vulnerability section within the Hybrid Cloud Console.
4. Review the vulnerability dashboard to see the overall CVE exposure for the RHEL 9.7 host (rhel-{guid}-1).
5. Use the search or filter to locate CVE-2025-43458 (WebKitGTK).
6. Click into the CVE detail view and review the affected systems, severity rating, and remediation options.
7. Select the RHEL 9.7 host and use the "Generate playbook" option to create an Ansible remediation playbook for this CVE.
8. Review the generated playbook (it is created by Red Hat and references Red Hat Ansible Automation Platform execution, but is not run in this lab).
9. Return to the vulnerability list and apply a filter for Critical and Important severity CVEs affecting the RHEL 9.7 host.
10. Review the filtered list and note the number of affected CVEs at each severity level.
11. Navigate to the Reports section within Red Hat Lightspeed vulnerability management.
12. Generate an Executive Report PDF and review its structure and contents.
13. Generate a Report by CVEs PDF, selecting specific CVE criteria.
14. Generate a Report by Operating System Versions and review the output.

### Key Takeaways

- Red Hat Lightspeed at the Hybrid Cloud Console surfaces CVE exposure across registered RHEL hosts without requiring manual scanning
- Ansible remediation playbooks for CVEs are generated by Red Hat and can be exported for use with Red Hat Ansible Automation Platform
- The vulnerability service supports multiple report formats (executive, CVE-based, OS version-based) for different audiences
- Filtering by severity (Critical/Important) helps teams prioritize remediation effort

### Infrastructure Notes

- The RHEL 9.7 host (rhel-{guid}-1) must have insights-client installed and registered to the Hybrid Cloud Console prior to lab start; pre-populated CVE data must be visible
- Shared organization account: concurrent learners share the same Hybrid Cloud Console organization — CVE data for the specific RHEL 9.7 host identified by {guid} is used to distinguish per-student work
- No AAP controller is provisioned; playbook generation is demonstrated but execution is not performed in this lab
