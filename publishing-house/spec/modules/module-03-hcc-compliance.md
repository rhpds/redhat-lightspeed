# Module Outline: module-03-hcc-compliance

### Brief Overview

This module walks learners through the compliance management workflow in Red Hat Lightspeed at the Hybrid Cloud Console. Learners create a CIS Level 1 Server SCAP policy, tailor it by customizing which rules are enforced, trigger a compliance scan from the RHEL 9.7 terminal, and then review the results and identify remediation steps for failed rules. The module combines one short terminal command (insights-client --compliance) with GUI-based policy creation and report review.

### Audience and Time

- **Target persona:** Linux system administrators and IT security operators; beginner level
- **Prerequisites for this module:** Completion of module 02; continued Hybrid Cloud Console session for the rhpd-lightspeed-lb1187 organization; terminal access to the RHEL 9.7 host (rhel-{guid}-1)
- **Estimated duration:** 30 minutes

### Learning Objectives

- Evaluate Red Hat Enterprise Linux regulatory compliance against a CIS Level 1 SCAP policy using Red Hat Lightspeed at the Hybrid Cloud Console
- Configure a SCAP compliance policy by customizing rules and assigning RHEL hosts
- Analyze failed compliance rules and identify Ansible-based remediation steps

### Lab Structure

| Section | Title | Duration |
|---------|-------|----------|
| 1 | Log in to the Hybrid Cloud Console (compliance section) | 2 min |
| 2 | Create a compliance policy (CIS Level 1 Server) | 8 min |
| 3 | Customize policy rules | 5 min |

| 5 | Review the compliance report and identify failed rules | 10 min |

### Detailed Steps

1. Navigate to the Compliance section within Red Hat Lightspeed at the Hybrid Cloud Console.
2. Click "Create policy" and select the CIS Level 1 Server SCAP profile from the SCAP Security Guide (SSG).
3. Assign the RHEL 9.7 host (rhel-{guid}-1) to the new policy.
4. Review the default rule set and disable or enable specific rules to tailor the policy to the Infinicorp requirements described in the lab narrative.
5. Save the policy.
6. Open a terminal session on the RHEL 9.7 host (rhel-{guid}-1).
7. Run `sudo insights-client --compliance` to execute the OpenSCAP scan and upload results to the Hybrid Cloud Console.
8. Return to the Hybrid Cloud Console Compliance section and navigate to the newly uploaded report for the RHEL 9.7 host.
9. Review the overall compliance score (percentage of passing rules).
10. Filter for failed rules and examine the details of at least two failed rules, noting the rule description, rationale, and remediation guidance.
11. Select one or more failed rules and use the "Generate playbook" option to create an Ansible remediation playbook.
12. Review the playbook structure (execution is not performed in this lab).

### Key Takeaways

- Red Hat Lightspeed at the Hybrid Cloud Console supports multiple compliance frameworks including CIS benchmarks, DISA STIG, HIPAA, and PCI DSS
- Policy tailoring allows organizations to align SCAP rule sets with their specific security requirements
- A single CLI command (`sudo insights-client --compliance`) uploads OpenSCAP results to the Hybrid Cloud Console for centralized reporting
- Ansible remediation playbooks for compliance failures are generated by Red Hat, parallel to the CVE remediation workflow in module 02

### Infrastructure Notes

- The RHEL 9.7 host (rhel-{guid}-1) must have insights-client and OpenSCAP (openscap-scanner and scap-security-guide packages) installed prior to lab start
- The compliance scan may take 2–4 minutes to complete and upload; lab instructions should account for this wait time
- The SCAP Security Guide version available on RHEL 9.7 determines which profiles and rules are available in the policy wizard
